🌐 1. วิธีเข้าทดลองใช้งานทันที

เปิดเว็บเบราว์เซอร์ (Chrome, Edge หรือเบราว์เซอร์ใดก็ได้) แล้วคลิกหรือพิมพ์ URL นี้ได้เลยครับ:

👉 http://127.0.0.1:5000
 (หรือ http://localhost:5000)

🎮 2. สิ่งที่สามารถทดลองเล่นได้ในหน้าเว็บ
🎴 โหมดทบทวนการ์ด (Flashcards 3D Mode)
การพลิกการ์ด 3 มิติ:
คลิกที่ตัวการ์ด หรือกดปุ่ม Spacebar บนคีย์บอร์ด เพื่อพลิกสลับระหว่างหน้าคำถามและหน้าคำตอบ
ปุ่มลัดคีย์บอร์ดประเมินตัวเอง:
กด → (ลูกศรขวา) เมื่อตอบได้ = "จำได้แม่นยำ!" (จะได้คะแนน + นับ Streak ไฟลุก 🔥)
กด ← (ลูกศรซ้าย) เมื่อยังจำไม่ได้ = "ยังจำไม่ได้" (ระบบจะเก็บไว้ให้ทบทวนซ้ำ)
ระบบคำใบ้ (Hint):
หากนึกไม่ออก ลองกดปุ่ม "💡 ดูคำใบ้" จะมีคำใบ้ค่อยๆ ปรากฏขึ้นมาช่วยเตือนความจำ
เสียงเอฟเฟกต์และพลุเฉลิมฉลอง:
มีเสียงสังเคราะห์ (Web Audio API) ตอนพลิกการ์ดและตอนตอบถูก สามารถเปิด/ปิดเสียงได้ที่ไอคอน 🔊 มุมขวาบน
เมื่อทบทวนจนจบสำรับ จะมีพลุกระดาษ Confetti จุดฉลองให้ด้วยครับ!
📋 โหมดจัดการรายการ (To-Do List Style)
สลับแท็บไปที่ "📋 รายการการ์ดทั้งหมด"
ติ๊กสถานะเหมือน To-Do: คลิกที่ไอคอน ⭐/⚪ หน้าแต่ละข้อ เพื่อเปลี่ยนสถานะว่า "จำได้แล้ว" หรือ "ยังต้องเรียนรู้"
ค้นหาด่วน (Live Search): พิมพ์คำค้นหา เช่น Cisco, Locality, IP ข้อมูลจะกรองให้ทันที
เพิ่มการ์ดของคุณเอง: กดปุ่ม "+ เพิ่มการ์ดใหม่" เพื่อบันทึกคำศัพท์หรือคำสั่งใหม่ลงในฐานข้อมูล SQLite
สำรองข้อมูล (Export JSON): กดปุ่ม "📥 สำรองข้อมูล" เพื่อดาวน์โหลดไฟล์การ์ดทั้งหมดเก็บไว้ได้
💻 3. วิธีเปิดรันด้วยตัวเองในครั้งถัดไป (Manual Run)

หากในอนาคตมีการปิดเครื่องหรือปิดโปรแกรม แล้วต้องการเปิดแอปขึ้นมาใหม่ ให้เปิด Terminal / PowerShell แล้วพิมพ์เพียง 2 บรรทัดนี้ครับ:

powershell
cd C:\Users\HOME\Desktop\FlashCardForDr.Somkid
python app.py

เมื่อขึ้นข้อความ [*] FlashDr. Flashcard App is running on http://127.0.0.1:5000 ก็สามารถเปิดเบราว์เซอร์เข้าใช้งานได้ทันทีครับ
